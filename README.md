# 유포리아투어 맛집 앱 (euforia-tour-restaurants.netlify.app)

스페인·포르투갈 도시별 맛집을 카드로 보여 주는 한 장짜리 앱입니다. Netlify 로 배포되며 `main` 에 올리면 자동 반영됩니다.

| 파일 | 내용 |
|---|---|
| index.html | 앱 전체 (맛집 목록 포함) |
| badge-verified.svg · 네이버_유포리아_인증맛집_뱃지.svg | 인증맛집 뱃지 |
| _작업자료/ | 신규 식당 DB 엑셀(2026-09)과 추가분 시드 — 앱에서는 쓰지 않는 작업용 파일 |
